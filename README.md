# dcp-triage

Standalone triage app for Display & Cell Pros, to be deployed at `triage.displaycellpros.com` as its own Vercel project, separate from the Shopify storefront.

`main` is a minimal buildable scaffold so the Vercel project can be created. The triage feature lands through pull requests.

- Framework: Next.js (App Router), TypeScript, Node 24
- Install: `npm ci`; build: `npm run build`; checks: `npm run check`
